# TaskFlow — Project Management API

A project management REST API with a simple frontend, built with Node.js/Express and PostgreSQL. Includes user authentication, task CRUD operations, and a health check endpoint.

## Getting Started

1. Install dependencies:

   ```
   npm install
   ```

2. Set up a PostgreSQL database and run the schema from `src/db/schema.sql`.

3. Start the server:

   ```
   npm start
   ```

4. Open `http://localhost:3000` in your browser.
